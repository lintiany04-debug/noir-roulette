# NOIR — European Roulette

海外カジノをテーマにした、ブラウザで遊べるルーレットアプリです。

## 操作方法

1. チップの金額を選択します。
2. 数字や RED / BLACK などのベット先をクリックします。
3.「SPIN THE WHEEL」を押すとルーレットが回転します。
4. 停止後に結果と配当が表示されます。

ベットなしでもスピンできます。初期残高は仮想チップ10,000です。

## 特徴

- ヨーロピアンルーレット（0～36の37ポケット）
- 木目と金属の質感、影、遠近感を使ったCanvas描画
- 玉の周回・減速・内側への移動・跳ね返りを表現するアニメーション
- 数字、ダズン、大小、偶奇、赤黒へのベット
- 配当計算、直近の結果履歴、サウンド切り替え
- スマートフォン対応レイアウト

## 使用技術

HTML / CSS / JavaScript / Canvas 2D / Web Audio API。
外部ライブラリやビルド作業は不要です。立体的な見た目は2D描画で表現し、玉の動きは補間によるアニメーションです。完全な3D物理シミュレーションではありません。

## 起動方法

`index.html` をブラウザで開いてください。

## GitHub Pagesで公開する方法

1. このリポジトリの Settings → Pages を開きます。
2. Source を「Deploy from a branch」にします。
3. Branch を「main」、フォルダを「/ (root)」にして Save を押します。
4. 公開完了後、Pages画面に表示されるURLを開きます。

## 補足

仮想チップ専用です。入金・換金機能はありません。残高や履歴はページの再読み込みでリセットされます。
